Frequently asked questions

Does Queue Manager modify or purge RabbitMQ queues?

No. Queue Manager is intentionally observational. It does not purge, delete, requeue, start, or stop queues or consumers.

Does it replace the RabbitMQ Management interface?

No. RabbitMQ Management provides detailed broker administration. Queue Manager focuses on bringing relevant RabbitMQ runtime information into Magento and relating it to Magento queue configuration and health.

Does Queue Manager inspect message payloads?

No. Message payload inspection is not part of Queue Manager.

Does the extension send usage telemetry to MWD?

No. Queue Manager does not send queue activity, RabbitMQ metrics, Magento operational data, or feature usage telemetry to MWD.

What should I provide if I need support?

Queue Manager includes a support report designed to provide useful diagnostic information while excluding sensitive operational data. Customers should review support reports before sending them.
