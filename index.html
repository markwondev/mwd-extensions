Why not just use RabbitMQ Management?

RabbitMQ Management is valuable infrastructure tooling. Queue Manager solves a different problem: understanding what RabbitMQ activity means in the context of Magento.

RabbitMQ Management

Answers infrastructure questions such as which queues exist, how many messages they contain, and what the broker is doing.

MWD Queue Manager

Connects broker runtime to Magento queue configuration, health, history, diagnostics, consumers, alerts, and support workflows inside Magento Admin.

Requirements and validation.

Compatibility claims are kept intentionally specific so you know what has actually been validated.

Validation baseline

  • Magento Open Source 2.4.9
  • PHP 8.5
  • RabbitMQ runtime
  • Magento cron for scheduled history and alerts

Runtime requirements

  • RabbitMQ Management API is required for live runtime metrics.
  • A dedicated RabbitMQ monitoring account is recommended.
  • Queue Manager does not provide destructive queue actions.
  • Other environments may work but should be validated before production use.
